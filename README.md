## 🇦🇫 阿富汗 / 美籍阿富汗裔文学

- **卡勒德·胡赛尼**（Khaled Hosseini，1965— ）
  - 美籍阿富汗裔作家、医生，生于阿富汗喀布尔，1980年因苏联入侵随家人移民美国。作品以阿富汗战乱为背景，聚焦人性的背叛与救赎，被视为当代**流散文学**代表人物之一。
  - **《追风筝的人》**（The Kite Runner，2003；你提到的《放风筝的人》通常即此书）：围绕风筝与阿富汗两个少年展开，讲述阿米尔与哈桑之间关于**人性背叛与救赎**的故事，属于**成长类文学**。
  - **《灿烂千阳》**（A Thousand Splendid Suns，2007）：以阿富汗战乱为背景，讲述两名阿富汗女性玛丽雅姆和莱拉在战乱、贫困与家庭暴力中缔结深厚情谊的故事。
  - **《群山回唱》**（And the Mountains Echoed，2013）：讲述一个阿富汗家庭几代人因贫困与战乱而骨肉分离、跨越半个多世纪的悲欢离合。
  - **《海的祈祷》**（Sea Prayer，2018/2019）：以父亲写给熟睡儿子的信的形式，描绘难民家庭的漂泊与希望。
